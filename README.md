# Jarvis AI Personal Assistant

A local AI assistant built using Python, Flask, Ollama and JavaScript.

## Features

- AI Chat Interface
- Ollama Local LLM
- Flask Backend
- Modern Responsive UI
- Conversation Management
- Typing Animation
- Voice Assistant (Work in Progress)

## Technologies

- Python
- Flask
- JavaScript
- HTML
- CSS
- Ollama
- Faster Whisper

## How to Run

1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start Ollama:
   ```bash
   ollama serve
   ```

3. Run Flask:
   ```bash
   python app.py
   ```

4. Open the frontend in your browser.
